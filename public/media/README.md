# Production media

Institute-supplied photography is organised by subject in this directory. The original JPEG data is retained; responsive AVIF and WebP derivatives are generated by Next.js image optimisation.

Keep natural colour and historically meaningful details. Do not remove annotations from archival sources, apply decorative filters, or overwrite these masters with generated derivatives.

## Derivatives

- `institution/ngagdra-kurizampa-drawing-green.png` is a tonal derivative of the drawing `institution/ngagdra-kurizampa.png`. It is trimmed to the drawing's edges and gradient-mapped from ink through the emblem's seal green to white. It is used for the homepage hero and on the Visit page. It is an illustration, not documentary photography. The master drawing is unchanged.
