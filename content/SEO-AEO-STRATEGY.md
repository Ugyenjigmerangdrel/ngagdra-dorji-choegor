# SEO + AEO strategy

## Principle
There is no separate technical shortcut for answer-engine visibility. Build strong indexable pages with unique institutional information, clear entities, accurate structured data and concise answer-first introductions.

## Implemented
- Server-rendered / statically generated App Router pages.
- Semantic headings and crawlable internal links.
- Per-route metadata, canonical URLs, Open Graph and Twitter metadata.
- Generated `sitemap.xml`, `robots.txt`, icon and Open Graph image.
- Organization + EducationalOrganization + WebSite JSON-LD.
- Person JSON-LD for H.E. Gyeltshen Trulku Rinpoche.
- Article + BreadcrumbList JSON-LD for story pages.
- Event publishing architecture designed around unique event detail URLs; do not emit fake Event markup before dates/locations are verified.
- RSS feed for editorial discovery.
- `llms.txt` as an optional machine-readable site guide; it is not treated as a ranking signal.
- Answer-first page intros that define Buddhist terminology in plain language before deeper material.
- Explicit content verification gates for changing facts.

## Content clusters to build authority
### Vajrayana education
Pillar page → curriculum explainers → teacher profiles → student/practitioner stories → retreat preparation.

### Retreat practice
Pillar page → Drubdey explainer → individual centre profiles → retreat journey → post-retreat advanced instruction.

### Living heritage
Pillar page → oral transmission → manuscripts → sacred arts → mandala studies → ritual traditions.

### Public life
Events → event detail → event archive → photo story → related teaching/reflection.

## Query intent coverage
Create pages that directly answer natural questions such as:
- What is Ngagdra Dorji Choegar?
- Where is Ngagdra Dorji Choegar in Bhutan?
- What is a Ngagdra?
- How does Buddhist retreat preparation work in Bhutan?
- What is a Drubdey?
- Who is H.E. Gyeltshen Trulku Rinpoche?
- What is studied at Ngagdra Dorji Choegar?
- What public religious events take place at Ngagdra?

Answer each in 40–80 clear words near the top, then add source-backed depth.

## After launch
- Verify domain in Google Search Console and Bing Webmaster Tools.
- Submit sitemap and monitor indexing.
- Validate structured data in Google Rich Results Test and Schema.org validator.
- Track Core Web Vitals.
- Build real citations/backlinks through Bhutanese cultural, educational, governmental, academic and Buddhist sources.
- Publish original photography with descriptive alt text and captions.
- Keep event, centre and leadership information current.
- Review Google Search Generative AI performance reports.
